## 核心设定数据（来自官方美术设定稿）

- 太空电梯总长约 **9 万公里**；方舟空间站位于 **3.6 万公里**地球同步轨道；末端 **9 万公里处设配重**。
- 地面基座位于赤道海面，设定**直径 3 公里、高 2 公里**，由 **3 根主塔 + 12 组发射塔（均分 3 组）+ 圆形发射平台**组成。
- **9 部轿厢**由 **216 根粗细不等的碳纳米缆绳**垂直连接。
- 轿厢第一视觉原型是**建筑工地的垂直施工升降机**（方箱、桁架、滚轮抱缆），内部为客机座舱布局。
- 发射时两侧硬质连杆像抛石机一样给轿厢叠加初速度，轿厢发动机点火，G 值激增。
- 返回大气层使用「冰盾」：太空注水瞬间结冰作为隔热罩。
- 整体美学：冷灰工业金属、旧化质感、**橙色警示涂装**、蓝白色聚变发动机焰。
