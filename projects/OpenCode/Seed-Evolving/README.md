# 太空电梯 3D 查看器（《流浪地球2》美术设定风格）

基于 **Three.js + Vite + TypeScript** 的程序化 3D 太空电梯查看器，依据电影官方美术设定稿（见 `docs/`）用几何体程序化重建，**不包含任何电影原始模型/贴图资产**，仅供学习。

## 功能

- 🖱️ 鼠标 / 触屏拖拽旋转、滚轮 / 双指缩放、右键 / 双指平移（OrbitControls，含阻尼与限位）
- 🌊 **赤道海上基地**：三层递减圆盘 + 中央发射竖井（危险涂装圈）+ 防波堤 + 水下阻尼浮筒，三条多车道长桥连椭圆人工岛，自定义 GLSL 波浪海面（太阳反光、浪沫）
- 🗼 **门式发射塔**（按官方概念图重制）：**6 根深色巨柱紧密环绕中央发射竖井**，由**多层横向箱梁连接成矩形门洞**（轿厢在柱间升降），中下部两道环形作业平台带护栏，柱顶设备舱/天线/红灯，顶部三层收束缆绳冠；外圈**满屏扇形斜拉钢索**
- 🛗 **SEV-03 轿厢（最终定稿造型）**：切角矩形扁舱（ExtrudeGeometry 八边形蒙皮）+ 顶面分块大货门 + **4 角开放式矩形抱缆框架**（竖框/顶梁/斜撑）+ 框架顶部带碟帽圆柱动力舱（橙环）+ 下垂长稳定鳍 + 前侧敞开舱门 + 一排小方窗/SEV-03 编号/检修盖/散热栅等 greeble；3 部不同导轨高度运行，到站熄火
- 🧵 **216 根碳纳米缆绳成束**（InstancedMesh）+ 4 根主导轨，穿过方舟站延伸至末端配重
- 🛗 **水平扁箱式爬升轿厢**（白色货运船体 + 顶部深色大货门 + 一排圆舷窗 + ARK-07 编号 + 四角设备舱 + 顶部抱缆门架双动力舱 + 双钟形喷管白蓝尾焰），保持水平沿导轨往返
- 🛰️ **方舟空间站**：约 **270° 弧形舱段**（非完整圆环，默认缺口朝相机）夹在**竖向密集缆绳走廊**上——三层弧轨 + 22 径向辐条 + 白色大舱段/开式桁架交替 + 端舱对接口 + 内环居住舱 + 4 道抱紧缆绳走廊的卡箍 + 对接臂/停泊飞船/太阳能翼，固定核心舱缆绳穿心
- 地面另有成排白色"门框"龙门发射工位、厂房（暖窗/UEG 巨牌）、球罐、管廊、龙门吊、集装箱等甲板细节
- ⚖️ 末端 **9 万公里模块配重段**；PMREM 环境反射、程序化金属/蒙皮/甲板/太阳能纹理、倒角几何、旋转环、航空灯、发射烟雾、地球/云/星空/大气辉光、Bloom
- 🌇 **黄昏电影级光影**（对应 MOREVFX 官方概念图）：可见太阳圆盘、**屏幕空间体积光束（god rays，夕阳穿过结构）**、低角度暖阳逆光 + 冷蓝补光、渐变天空、电影调色叠加与暗角、大气雾、金色海面反光、两圈**低空金云**与平台周边海面水汽；防波堤/长桥密集暖灯、厂房随机亮窗、UEG 巨牌
- 🔩 **表面细节**：程序化法线凹凸（板缝/铆钉/噪点）、金属蒙皮贴图、塔身 UEG-01/02/03 编号贴花、外挑检修平台+护栏、顶部缆绳锚固冠
- 🚢 **尺度参照物**：3 艘远海货轮（船体/舰桥/集装箱）、3 架带尾迹的返航飞机、桥上 18 辆车流、**3 部轿厢同时在不同高度/导轨运行**（到站熄火）
- 🎥 **轿厢跟随视角**：右上「跟随轿厢」按钮，镜头平滑跟随轿厢沿缆绳上升（保持当前环绕角度，可继续旋转/缩放），手动拖拽或点复位/热点即退出
- 🚀 **发射演出**：右上「发射」按钮触发——井内强光脉冲、扩散冲击波环、蒸汽喷发、全屏闪光（暂停时不会触发）
- ⏸️ **全局暂停/播放**（右上「⏸ 暂停」按钮或快捷键 `P`）：冻结轿厢、旋转环、烟雾、云、海浪、船/车/飞机等所有动画，相机仍可自由旋转缩放以便观察
- 🔵 5 个热点（基地 / 缆绳束 / 轿厢 / 方舟站 / 配重），点击镜头平滑聚焦并弹出基于官方设定的说明
- 📱 响应式适配移动端

## 本地运行

```bash
npm install
npm run dev      # http://localhost:5173 （开启局域网监听，方便手机测触屏）
npm run build    # 类型检查 + 生产构建到 dist/
npm run preview
```

调试机位可用 URL 参数覆盖初始相机：`?cam=x,y,z&look=x,y,z`（世界坐标，海面基地位于 y≈1200）。

## 设定依据（摘自 `docs/README.md`）

电梯总长约 9 万 km，方舟站在 3.6 万 km 同步轨道，末端 9 万 km 设配重；
地面基座设定直径 3 km、高 2 km，由 3 主塔 + 12 发射塔（3 组）+ 圆形平台组成；
9 部轿厢由 216 根碳纳米缆绳牵引；轿厢原型是工地垂直施工升降机。
真实比例无法同屏展示，项目做了艺术化压缩，常量集中在 `src/config.ts`。
