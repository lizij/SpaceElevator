## 实际问题与修正

- 初始模型采用多个独立轿厢零件，全景约 1,091 绘制调用；合并相同材质的轿厢网格后降到约 120，钢构使用 InstancedMesh。
- 第一版轿厢镜头被主塔挡住。改用偏离塔中心的缆索通道与另一侧相机；近景隐藏介绍大标题。通过截图逐次检查，不仅检查相机坐标。
- 缆索初版集中为一束，与四角驱动结构不对应。改为每通道四角各六根，共 216 根；粗细是视觉近似。
- 未声明 favicon 导致首轮浏览器 404。新增自绘 SVG favicon 后消除。
- 第一版直接从 WebGL Canvas 读像素得到空结果：默认 WebGL 绘制缓冲不保留，读取时机不可靠。改用浏览器实际 Canvas 截图解码 PNG，未为测试开启昂贵的 `preserveDrawingBuffer`。
- 标注关闭后的立即断言遇到下一帧才更新的时序，测试等候下一帧，并补充 `[hidden]` 明确样式。
- 多个 SwiftShader 页同时保持渲染导致测试后段超时。用完即关闭页面，再串行验证子路径与减少动态偏好；最终完整重跑通过。
- 初始 Vite 7.1.12 的公共 registry 安全审计有一项高风险汇总。更新到同主版本修复版 7.3.7，最终公共 registry 审计 0 漏洞。未执行强制跨大版本升级。
