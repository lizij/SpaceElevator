## 2. 关键设定与实现对照

电影公开设定中的核心数字：

- 系统总高 **90,000 km**
- 同步轨道空间站 **36,000 km**
- 海上基座 **直径 3 km × 高 2 km**
- 碳纳米缆索 **216 根**
- 轿厢 **9 部**
- 单部轿厢运力约为现役最大运载火箭的 **4 倍**
- 基座由 **3 座主塔集群**、**12 座发射塔（3 组 × 4 座）**、圆形发射平台、阻尼器与驱动平台构成
- 配重位于 **90,000 km**

| 部位 | 电影 / 公开设定 | 本作实现 |
| --- | --- | --- |
| 总高 | 90,000 km | 轨道场景：地球半径 `R = 1`，配重 `1 + 90000/6371 ≈ 15.13R` |
| 同步轨道站 | 36,000 km | 轨道场景：`1 + 36000/6371 ≈ 6.65R` |
| 海上基座 | Ø3 km × 2 km | 基地场景：外环半径约 1.5 km，主塔高 1.9 km |
| 主塔 | 3 座主塔集群 | 3 个集群按 120° 分布；每簇 1 根中央主桅 + 3 根外围柱 + 环带/斜撑/平台 |
| 发射塔 | 12 座，3 组 × 4 座 | 12 座发射塔分 3 组布置，带吊机、勤务平台、发射坪与泛光灯 |
| 缆索 | 216 根 | 216 根 InstancedMesh 缆索，分 3 圈束布置；基座场景为 26 km 局部视觉段 |
| 轿厢 | 9 部 | 9 部宽扁板式轿厢；主角为 `SE-02`，四角夹缆塔 + 中央 52 m 通道 |
| 发射平台 | 圆形平台 | 圆形主平台 + 内圈海水 + 连接核心岛的栈桥 + 外圈设备带 |
| 阻尼器 / 驱动平台 | 基座下部 | 锚泊钟形结构、4 组巨型阻尼器、下部驱动舱与支撑桁架 |
| 空间站 | 36,000 km 同步轨道 | 双环空间站、金色对接环、4 组太阳能板、对接臂与天线 |
| 配重 | 90,000 km | 圆柱配重 + 环形桁架 + 端盖机械 + 散热板 + 太阳能板 + 航标灯 |
| 海面/天空 | 赤道海上、晨昏 | 自定义海面 shader（深浅水、菲涅耳、浪花、太阳高光）+ 天空穹顶 shader |

## 3. 视觉语言

从公开美术图中提取并落到材质/灯光里的视觉规则：

- **银灰金属主体**：`hull` / `hullShade` / `steelLight` 构成大面积壳体，金属度 0.4–0.8，粗糙度 0.3–0.5。
- **深色机械 greeble**：`steel` / `steelBlue` / `hullDark` 用于桁架、环带、检修平台与结构缝，形成“白壳体 + 深色骨架”的对比。
- **橙色安全色**：轿厢边缘、发射平台、系泊结构、警示带与部分航标使用橙色，作为画面里的小面积高饱和点缀。
- **冷青绿海面**：海面 deep/shallow 取青绿到深蓝，天空在晨昏时偏暖，深夜时转为近黑蓝。
- **清冷晨光 / 黄昏**：默认 `dawn` 主题使用低角度暖阳、暖灰雾和冷色补光；`night` 主题压低环境光，打开平台灯、轿厢窗灯、航标与空间站点光。
- **尺度感**：基座场景用补给船、吊机、栏杆、轿厢与人的尺度参照；轨道场景用公里标签、标尺和“地球—空间站—配重”的纵向构图传达 90,000 km。

## 4. 建模取舍

1. **基地缆索只做 26 km 局部段**  
   在 3 km 基座的镜头里，真实 90,000 km 缆索会在透视上变成一条几乎不可见的线。基地场景用 26 km 的视觉段，让 216 根缆索、9 部轿厢和夹缆结构在近景中可读；完整比例放到轨道场景。

2. **发射塔与平台设备风格化**  
   12 座发射塔保留“3 组 × 4 座”的布局、吊机/勤务平台/发射坪/泛光灯等识别特征，但不逐件复刻电影资产。原因是实时 WebGL 的性能预算与程序化建模的可维护性。

3. **轿厢优先还原轮廓与识别点**  
   宽扁船体、黑色太阳能顶、四角夹缆塔、橙色对接环、侧设备舱、窗带与外部灯带是重点；内部结构、舱门机械等不做展开。

4. **空间站与配重是“可读的工程结构”**  
   双环、对接环、太阳能板、桁架、散热板、航标灯等元素齐全；在 36,000 km/90,000 km 的尺度下，不追求电影镜头的逐帧一致。

5. **地球贴图使用公开 NASA/Three.js 资源**  
   昼面、夜面、高光与云层分别使用 2048/1024 贴图；地球半径归一化，海面高光、云层、大气边缘与夜景灯光都由 shader 组合。
