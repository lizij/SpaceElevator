# 参考项目对照后的 3 轮针对性重构（Round 10–12）

> 日期：2026-10-21  
> 目标：针对 Op55 / GPT 对比中暴露的**结构、比例、镜头**问题，不再继续小修小补。

## 参考结论

- `SpaceElevatorOp55`：低机位、细塔身 + 宽塔脚、深色工业甲板、PBR 贴图；整体电影感最强。
- `SpaceElevatorGPT`：MIT 源码，`Builder` 合批、`loft/chamfer` 放样、开放夹持、开放空间站；工程方法最值得借鉴。
- 两者都是程序化生成，所以之前“程序化上限 76%”不成立；差距来自我们的**模型架构、比例和镜头**。

## Round 10：基座比例 + 低机位

- 三塔半径 **650 → 450m**
- 主塔宽度 **210 → 168m**（整体缩放 0.8）
- 主环半径 **700 → 480m**
- 发射塔半径 **340–460 → 220–310m**
- 中心人工岛半径 **790 → 600m**
- 基座相机从 **3,900m 海拔 / 5–6km 距离** 降到 **约 1,050m 海拔 / 4.2km 距离**
- 保留宽楔形塔基/白色塔脚，让“细塔身 + 宽塔脚”关系更接近参考
- 结果：三塔不再像沙盘上散开的柱子，低机位下塔体高度和集群密度明显更接近 Op55

## Round 11：轿厢放样壳体

- 轿厢主体从 `RoundedBox` 改为 **6 层截面 loft**：
  - 底部收窄 0.82
  - 中部 1.0
  - 顶部肩部 0.88 / 0.82
- 侧面设备模块从 58×82×184 缩到 50×74×168，减少“大平板遮住壳体”
- 保留分层冰盾、四角夹持、金色液压杆
- 结果：轿厢开始有上宽下窄的截面变化，不再完全是等宽方盒

## Round 12：空间站开放环

- 实心环甲板改成 **12 段带间隙的扇形甲板**
- 保留同心桁架环、径向框架、双塔核心、栏杆、对接端口、长船坞
- 结果：环平台不再是一整块白色飞碟，能看到内部桁架和开口，更接近 GPT/官方的开放环结构

### 对比上一版的结构改善

- 基座：三塔更紧、塔身更细、塔脚更宽、镜头更低，整体尺度感明显更像 Op55
- 轿厢：主体有了截面收分，但夹持总成仍偏“盒 + 杆”
- 空间站：环平台开放了，但环舱/双塔细节仍不如 GPT
- 材质：仍是程序化 roughness + SSAO，不是 Op55 的 PBR atlas

## 仍然存在的差距

1. 基座塔体细节仍不如 Op55：缺 PBR 面板 atlas、密集百叶/检修口/管线。
2. 轿厢夹持不是开放式叉臂/大型液压总成；冰盾仍偏盘状。
3. 空间站双塔/环舱仍偏简单，船坞捕获臂不足。
4. 程序化几何没有合批；继续加细节会撞 draw call。
5. 相机/UI 还没有 Op55 的 8 个预设和甲板/海拔读数。

## 下一步建议

- **P0**：把 GPT 的 `Builder` 合批 + `loft/chamfer` 原语引入当前项目，给基座/轿厢/空间站一次性加密度。
- **P0**：轿厢夹持改成开放叉臂 + 滚轮 + 液压缸；冰盾改 4/8 片可动翼。
- **P1**：基座换 2K PBR atlas（自建/授权，不复制 Op55 资产）+ 深色甲板标线。
- **P1**：空间站环舱/双塔/船坞继续细化。
