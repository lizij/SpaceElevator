# 太空电梯 Web 3D 还原方案

> 实现状态：v1 已落地到 `src/`，可运行 `npm run dev` 查看。本文件保留为设计依据与后续迭代规格。

> 目标：在浏览器里尽可能还原《流浪地球2》太空电梯的**轮廓、比例、关键机械特征、色彩和镜头感**，同时保留鼠标/触屏自由旋转、缩放和聚焦能力。
>
> 前提：官方没有公开 3D 模型，公开设定图也没有正交三视图。因此这是“**高保真同人近似重建**”，不是 1:1 数字孪生。最终站点不直接使用官方图片、Logo 或贴图。

## 1. 设计原则

### 1.1 先像，再细

观众判断“像不像”的顺序是：

1. **剪影**：三根主塔、环梁、索网、圆形港池、四角轿厢、环形空间站；
2. **比例**：基座 3 km / 2 km，缆索 90,000 km，轿厢数十米；
3. **机械特征**：四角夹持、冰盾、发射双塔、对接环；
4. **材质与光**：灰白装甲、深色钢、金色液压、海雾、硬太阳光；
5. **greeble**：管线、栏杆、梯子、警示条、编号。

所以第一个里程碑不是“做完模型”，而是“灰盒剪影在电影镜头里成立”。

### 1.2 真实比例 + 可读性夸张

真实比例必须遵守，否则会变成“一根杆子挂个盒子”。但三个地方允许视觉夸张：

- **L0 轨道层**：基座缩成一个带光晕的标记；空间站/配重略微放大，保证可读；
- **缆索**：用屏幕空间线宽，不按真实直径画；
- **雾/蒸汽/光晕**：比真实更浓，用来表达尺度和空气感。

### 1.3 电影模式 + 工程模式

同一套模型，两套光照/后期/UI：

| 模式 | 用途 | 特征 |
|---|---|---|
| 电影模式 | 默认展示、截图、作品集 | 低机位、海雾、暖橙尾焰、Bloom、轻微 DOF、暗角、无标注 |
| 工程模式 | 看细节、讲解 | 中性布光、无雾、线框/标注、热点、尺寸信息、可剖切 |

这个切换能让“还原电影”和“观看细节”同时成立。

## 2. 分层尺度架构

### 2.1 层级定义

| 层级 | 比例 | 主要内容 | 相机距离 | 说明 |
|---|---|---|---|---|
| L0 轨道层 | 1 unit = 1,000 km | 地球 r=6.371、缆索 90、空间站 36、配重 90 | 120–300 unit | 基座用光点标记；空间站/配重适度放大 |
| L1 基座层 | 1 unit = 10 m | 基座 300×200 unit、港池、三塔、12 组发射塔、9 轿厢 | 400–1,500 unit | 缆索只画近端几 km，远处渐隐 |
| L2 轿厢层 | 1 unit = 0.1 m | 轿厢约 400 unit 宽、四角夹持、冰盾、缆索接头 | 400–1,200 unit | 背景简化，保留发射塔/主塔局部 |
| L3 空间站层 | 1 unit = 1 m | 环形站约 2,500 unit 直径、中央脊柱、船坞 | 3,000–6,000 unit | 配重可复用同一层 |
| L4 内景（可选） | 1 unit = 0.1 m | 客舱/控制室/货舱 | 200–800 unit | 第二阶段再做 |

### 2.2 切换方式

- 每层内部：`CameraControls` + 阻尼 + 缩放限制；
- 层与层之间：相机飞行 1.0–1.4 s + 0.2 s 交叉淡入；
- 保持目标在画面中的位置，避免“跳一下”；
- 进入下一层用**双击部件/点击热点/层级导航**，滚轮只在当前层内缩放；
- 到当前层缩放边界时，出现“进入基座 / 进入轿厢”的半透明提示，不自动跳转，避免误触。

### 2.3 为什么不用一个场景

- 地球半径 6,371 km，缆绳 90,000 km，基座 3 km，轿厢约 30–50 m；
- 在 L0 尺度下，基座不到 0.03 px，轿厢是亚像素；
- 单场景需要极大的 far/near 比和 float32 精度，容易出现 z-fighting、抖动、缆索闪烁；
- 分层后每层只渲染“看得见”的范围，near/far 可以收紧，精度和性能都更好。

## 3. 场景规格

### 3.1 L0 轨道层

**地球**
- 半径 6.371 unit；4K day map + 4K night lights + 2K clouds + 法线/粗糙度；
- 云层独立球壳，缓慢旋转；
- 大气：背面球 + Fresnel shader，边缘蓝白色；
- 海面高光：用 roughness/specular map 近似，不在 L0 做真实反射。

**缆索**
- 从基座表面沿 +Y 到 90 unit；屏幕空间细线/ribbon；
- 靠近基座处稍亮，向上逐渐变细/变暗；
- 9 部轿厢用 9 个移动光点表示，沿缆索缓慢移动。

**空间站 / 配重**
- 空间站在 36 unit，环形轮廓 + 中心脊柱 + 暖白窗光；
- 配重在 90 unit，小十字/花环 + 冷白灯；
- 在 L0 允许把空间站/配重放大约 1.5–2 倍，否则太小。

**背景**
- 星空（程序化 points，避免贴图接缝）；
- 太阳：方向光 + 屏幕空间光晕，角度低一点，形成地球边缘光；
- 地球夜景城市灯光只在暗面出现。

### 3.2 L1 基座层

**总布局（推定，按 3 km 直径）**

![基座推定布局](reference/base_plan_schematic.png)

| 部件 | 尺寸/位置 | 做法 |
|---|---|---|
| 外圈港池 | 半径 1,500 m | 圆形防波堤 + 放射栈桥 + 码头 |
| 三主塔 | 高 2,000 m，位于半径约 900 m 的 120° 三点 | 矩形竖向体 + 竖肋 + 凹槽 + 维护平台 |
| 环梁 | 高度约 600–700 m，半径约 900 m | 三角/环形桁架连接三塔 |
| 中央井 | 半径约 180 m | 216 缆索汇聚的深井 + 发射平台 |
| 12 组发射塔 | 3 组 × 4 个发射位，围绕中央井 | 每组 2 座格构塔 + 硬质连杆 + 发射台 |
| 水下阻尼器 | 平台下方 | 大直径圆柱/锥体，部分在水下 |
| 港区 | 外圈 | 船、吊机、仓库、道路、车辆、灯 |

**主塔**
- 白色/浅灰装甲，竖向分缝；
- 深色凹槽里放电梯井、管线、维护平台；
- 塔顶有机械平台和缆索连接臂；
- 塔身中下部有环形桁架/支撑；
- 塔基斜撑落到港池边缘。

**发射塔**
- 深色钢格构，双塔夹一个发射位；
- 硬质连杆从塔身伸向轿厢；
- 发射台是带格栅的厚板，周围有管线、护栏、警示条；
- 点火时四道尾焰 + 蒸汽 + 镜头震动。

**海面**
- 自定义 shader：深青灰水色、Fresnel、细法线波、靠近结构处的白沫；
- 雾：`FogExp2` + 低空体积感（可用多层半透明平面/粒子伪体积）；
- 远处加蓬行星发动机剪影，增加世界观。

### 3.3 L2 轿厢层

**主体（推定）**
- 宽约 40 m、高约 26 m、深约 32 m；
- 四角夹持塔高约 18 m，向外突出；
- 顶部深色面板约 28×20 m；
- 冰盾展开直径约 46 m。

**部件**
- 四角夹持：白色立柱 + 金色液压臂 + 黑色滚轮/夹块；
- 顶部：深色分缝面板、蓝色圆盖、检修门；
- 侧面：设备舱、舷窗、红色警示条、编号；
- 底部：四台推进器、货舱门、逃逸滑板、冰盾铰链；
- 顶部对接：吸盘连接处、空间站对接接口、引擎固定卡扣。

**冰盾**
- 收起时贴合底部，像多层装甲板；
- 展开时分成 6–8 瓣，形成浅碟/花瓣；
- 半透明冰材质 + 内部裂纹 + 冷蓝色边缘光；
- 动画用关节旋转 + 缩放，不直接 morph。

### 3.4 L3 空间站层

- 环形主桁架：主环 + 内外副环 + 放射辐条；
- 中央脊柱：贯穿缆索的纵向结构；
- 下部船坞：捕获框架、对接臂、灯光；
- 外围：太阳能板、散热板、推进器、停靠飞船；
- 细节：舷窗暖光、警示灯、桁架节点、管线；
- 电影里空间站还在建造，建议保留部分脚手架/工程船，增加故事感。

### 3.5 配重

- 中央脊柱 + 放射支架 + 设备舱 + 太阳能/散热板；
- 顶部平坦平台；
- L0 只读轮廓，L3 展示细节；
- 三种官方方案可做成“方案切换”彩蛋，但不是首版必需。

## 4. 镜头设计

### 4.1 开场（6–8 s，可跳过）

1. 海面低机位，雾，远处三塔剪影；
2. 缓慢向前推进，船/吊机从前景划过；
3. 镜头沿塔身上升，缆索逐渐填满画面；
4. 穿过云层，切到轨道视角，地球 + 90,000 km 缆索；
5. 停在全景，交还控制。

### 4.2 预设镜头

| 名称 | 机位 | 目标 | 情绪 |
|---|---|---|---|
| `hero_base` | 海面 120 m 高，距基座 2.5 km | 主塔中段 | 压迫、巨物 |
| `launch` | 发射台侧后方 200 m | 轿厢/双塔 | 点火、蒸汽 |
| `climb` | 轿厢下方 150 m，仰拍 | 轿厢底部/缆索 | 上升、速度 |
| `orbit` | 地球外 200,000 km | 地球+缆索 | 孤独、尺度 |
| `station` | 空间站外 4 km | 环形站 | 工业、繁复 |
| `counterweight` | 配重外 3 km | 配重 | 终点、荒凉 |

切换用 `CameraControls.setLookAt`，`smoothTime` 1.0–1.4 s；切换期间禁用轨道控制，结束后恢复。

### 4.3 电影感参数

- 焦距：基座 24–35 mm 广角；轿厢 50–85 mm；空间站 35–50 mm；
- 低机位、仰拍、塔顶出画；
- 浅景深只在大屏/电影模式开启；
- Bloom 只对尾焰、窗光、警示灯、地球边缘；
- 轻微暗角 + 细颗粒，避免“游戏感”；
- 不要过度 lens flare，一处即可。

### 5.3 性能预算

| 层级 | 三角面 | Draw calls | 纹理 |
|---|---|---|---|
| L0 | < 120k | < 40 | 地球 4K，云 2K |
| L1 | < 600k | < 150 | 2K PBR + trim sheet |
| L2 | < 800k | < 120 | 2K |
| L3 | < 500k | < 100 | 2K |

- 桌面目标 60 fps（M1/M2 或同级独显），移动端 30 fps；
- DPR 上限 2；移动端 1.5–2；
- 桁架、栏杆、灯、缆索夹块全部 `InstancedMesh`；
- L1/L2/L3 懒加载，首屏只加载 L0；
- 使用 `PerformanceMonitor`/`AdaptiveDpr`，帧率低于阈值自动降级；
- 阴影只开 L1 的一盏主方向光（2048），L2 用接触阴影，L0 不开阴影。

## 6. 材质、灯光与后期

### 6.1 材质

| 部位 | 材质 |
|---|---|
| 主塔/轿厢装甲 | 白色/浅灰漆面金属，roughness 0.35–0.5，轻微划痕 |
| 深色结构 | 深灰钢，metalness 0.8，roughness 0.4，边缘磨损 |
| 金色液压 | 黄铜/钛金，metalness 1.0，roughness 0.25 |
| 缆索 | 深灰/黑色，近景金属高光；远景自发光细线 |
| 冰盾 | 半透明冰，transmission/opacity，冷蓝边缘，内部裂纹 |
| 海面 | 深青灰，Fresnel，细法线，白沫 |
| 空间站 | 灰白金属 + 暖白窗光 + 蓝色太阳能板 |

### 6.2 灯光

- L1：低角度太阳（暖白）+ 天空半球光（冷蓝）+ 港区暖橙实用光；
- L2：太阳 + 地球反光（冷蓝补光）+ 推进器自发光；
- L0：强太阳 + 极低环境光，地球边缘光；
- L3：硬太阳 + 空间站窗光/警示灯；
- 电影模式加体积雾/蒸汽；工程模式用中性三点光。

### 6.3 后期

- ACES Filmic tone mapping，exposure 0.9–1.1；
- Bloom：尾焰、窗光、警示灯、地球边缘；
- Vignette、细颗粒、轻微色差（电影模式）；
- DOF 仅桌面电影模式；
- SMAA/MSAA；移动端关闭 DOF/SSAO；
- 颜色管理：sRGB 贴图，输出 sRGB。

## 7. 交互与 UI

### 7.1 操作

- 左键/单指拖动：旋转；
- 滚轮/双指捏合：缩放；
- 右键/双指拖动：平移（可选）；
- 双击部件/热点：聚焦并进入对应层级；
- `R` 重置，`F` 聚焦，`+/-` 缩放；
- 移动端 `touch-action: none`，避免页面滚动/下拉刷新。

### 7.2 UI

- 顶部：`太空电梯 / THE SPACE ELEVATOR`，副标题“《流浪地球2》同人三维重建”；
- 左侧：层级导航（全景/基座/轿厢/空间站/配重）；
- 右侧：对数高度尺（0 / 2 km / 36,000 / 90,000 km）+ 当前高度；
- 底部：操作提示、电影/工程模式、自动巡游、重置、全屏；
- 信息卡：点击主塔/发射塔/轿厢/冰盾/空间站，显示名称、尺寸、功能、设定说明；
- 加载页：进度 + 一句设定文案；
- 首次进入：3 秒操作提示，之后淡出；
- 版权声明：非官方同人作品，设定灵感来源《流浪地球2》。

### 7.3 自动巡游

按 `hero_base → launch → climb → orbit → station → counterweight` 顺序自动飞行，每站停留 4–6 s；用户一操作就退出自动模式。

## 9. 实施阶段

### Phase 1：灰盒与镜头（2–3 天）

- 脚手架、Canvas、CameraControls；
- L0 地球/星空/太阳/缆索/空间站/配重灰盒；
- L1 基座三塔/环梁/港池/发射塔灰盒；
- 层级切换、6 个预设镜头；
- 部署到静态站点，先看“像不像”。

### Phase 2：高细节程序化（4–6 天）

- 主塔竖肋/凹槽/维护平台/塔顶机械；
- 12 组发射塔、硬质连杆、发射台；
- 轿厢四角夹持、顶部面板、冰盾、推进器；
- 空间站环桁架、船坞、太阳能板；
- 港区船/吊机/道路/灯；
- 缆索 LOD 与 shader；
- 性能与 LOD 调整。

### Phase 3：电影化（3–5 天）

- 海面 shader、雾、蒸汽、云；
- 四点布光/地球反光/尾焰光；
- Bloom、暗角、颗粒、DOF；
- 开场动画、自动巡游、发射动画；
- UI、热点、信息卡、高度尺；
- 电影/工程模式切换。

### Phase 4：移动端与 QA（2–3 天）

- 移动端 DPR/性能/触控；
- 真机测试（iPhone Safari、Android Chrome）；
- 截图回归、加载优化、错误兜底；
- 最终版权声明与部署。

**总计：约 2 周得到“高保真可展示版”；如果加内景和大量 greeble，约 3–4 周。**

## 10. 验收标准

- 第一眼能认出：三塔、环梁、索网、圆形港池、四角轿厢、环形空间站、90,000 km 缆索；
- 6 个预设镜头 + 自由旋转/缩放/触屏；
- L0/L1/L2/L3 切换无跳变、无 z-fighting；
- 桌面 60 fps、移动端 30 fps；
- 首屏 < 5 s（L0 资源），L1/L2/L3 懒加载；
- 电影模式可截图，工程模式可看细节；
- 不包含官方图片、Logo、模型或贴图；
- 静态部署，无后端。

## 11. 风险

| 风险 | 影响 | 规避 |
|---|---|---|
| 程序化模型“像但不够真” | 近景 greeble 不足 | 模块化 kit + 实例化 + 关键 hero 部件手工细化 |
| 216 根缆索性能/闪烁 | 掉帧、摩尔纹 | 远景 shader 线束，近景实例化圆管，距离淡出 |
| 多尺度切换跳变 | 眩晕、出戏 | 相机飞行 + 交叉淡入 + 保持构图 |
| 雾/后期掩盖细节 | 看不清模型 | 电影/工程双模式，工程模式关雾 |
| 移动端发热 | 掉帧 | DPR 限制、LOD、按需加载、关闭 DOF/SSAO |
| 版权 | 下架/商用风险 | 原创近似、非商业、标注来源、不上官方素材 |
| 没有 Blender | 高模受限 | 首版程序化，后续安装 Blender 或外包 hero 资产 |

## 12. 待确认

1. **视觉优先级**：电影氛围优先，还是工程细节优先？建议默认电影模式，保留工程模式。
2. **移动端**：是否必须首版支持？建议必须，至少 30 fps。
3. **内景**：首版是否要进轿厢内部？建议不做，先把外观和尺度做好。
4. **资产路线**：先用程序化几何，还是安装 Blender 做高模？建议先程序化跑通，再替换 hero 部件。
5. **上线范围**：个人作品集/非商业展示，还是可能有商业用途？后者需要处理版权和官方授权。

确认后按 Phase 1 开始搭脚手架和灰盒。
