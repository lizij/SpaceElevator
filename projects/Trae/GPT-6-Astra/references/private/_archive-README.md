## 还原范围

本轮保留原展台的非等比高度、单轿厢与四组主导缆索。文章提到的全系统九部轿厢、216 根缆绳、同步轨道至配重的真实距离没有完整建模。地球仍是程序生成的示意地表，不对应真实大陆。冰盾铰接角度、隐藏管线、微小紧固件及部分舱底细节依据可见图版进行近似设计；没有电影原始网格、材质扫描或完整尺寸图，不能标称电影资产级复原。
