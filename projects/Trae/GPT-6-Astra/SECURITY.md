# Security policy

## Supported version

The latest revision on the default branch is the only supported version.

## Reporting a vulnerability

Do not publish credentials, exploit details, personal data, or other sensitive material in a public issue. Use GitHub's **Security → Report a vulnerability** flow when it is available. If private vulnerability reporting is unavailable, contact the repository owner through their GitHub profile without including sensitive details in a public message.

Reports should describe the affected page or file, reproduction conditions, likely impact, and a safe way to validate the fix. Please allow time for triage before public disclosure.
